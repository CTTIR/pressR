# Bind Historical Cycles to Their Exact Measurements

Bind Historical Cycles to Their Exact Measurements

## Usage

``` r
pr_lock_cycles(trial, cycles)
```

## Arguments

- trial:

  A [pr_trial](https://cttir.github.io/pressR/dev/reference/pr_trial.md)
  object.

- cycles:

  Historical cycle table with frame indices and timing.

## Value

A reference object for
[`pr_temporal_profile()`](https://cttir.github.io/pressR/dev/reference/pr_temporal_profile.md).
